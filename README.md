# 豆瓣电影 Top250 数据采集项目

## 项目简介
基于 Python 实现豆瓣电影 Top250 榜单的自动化批量爬取，提取排名、电影名称、评分、一句话短评等核心字段，通过多层节点解析与空值处理完成数据清洗，最终输出标准化 CSV 数据集，可直接用于后续数据分析、可视化与入库。

## 技术栈
- 编程语言：Python
- 网络请求：Requests
- 页面解析：BeautifulSoup4
- 数据输出：CSV 结构化文件
- 反爬处理：请求头伪装、频率控制、异常兜底

## 核心实现
1.  分页遍历全量 250 条电影数据，覆盖完整榜单
2.  多层级 DOM 节点解析兜底，最大化短评字段提取成功率
3.  内置空值统一填充逻辑，输出数据规范无缺失
4.  采用 utf-8-sig 编码输出，兼容 Excel 直接打开无乱码
5.  请求间隔控制，降低反爬拦截风险

## 难点与解决方案
### 1. 高频请求触发反爬，返回 403 中断

**具体困难**：连续无间隔请求 3 页以上（每页 25 条），豆瓣直接返回 403 状态码，页面内容为空，爬取直接中断；偶发会跳转到人机验证页，无法继续获取数据。
**具体解决**：

- 请求头固定添加完整的 Chrome User-Agent，不使用 Python requests 的默认标识
- 每请求完一页，强制 `time.sleep(1)`，把请求频率控制在 1 页 / 秒
- 用 `try-except` 包裹请求逻辑，失败后等待 2 秒自动重试，最多重试 2 次；仍失败则记录该页跳过，不终止整个程序
 ### 2. 短评节点缺失，程序报错崩溃

**具体困难**：部分电影没有「一句话短评」（对应 `class='inq'` 的 span 节点不存在），直接调用 `.text` 属性会抛出 `AttributeError: 'NoneType' object has no attribute 'text'`，导致整条数据解析失败，程序直接终止。
**具体解决**：

- 先取节点再判断：`comment_tag = item.find('span', class_='inq')`
- 非空兜底赋值：`comment = comment_tag.text.strip() if comment_tag else "暂无短评"`
- 把单条电影的解析逻辑全部包裹在 `try-except` 里，单条解析失败不影响其余数据采集
  ### 3. CSV 文件用 Excel 打开中文乱码

**具体困难**：用默认 `utf-8` 编码保存 CSV 后，Windows Excel 打开时所有中文字符显示为乱码，需要手动用记事本转码才能查看。
**具体解决**：

- 打开文件时，编码从 `encoding='utf-8'` 改成 `encoding='utf-8-sig'`
- 靠 UTF-8 BOM 字节标记让 Excel 自动识别编码，双击就能正常显示中文，无需额外转码操作
