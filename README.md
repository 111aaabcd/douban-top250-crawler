# 豆瓣电影 Top250 数据采集项目

## 项目简介

基于 Python 实现豆瓣电影 Top250 榜单数据采集，提取排名、电影名称、评分、榜单短评等字段，输出标准化 CSV 数据集，可用于后续数据分析、可视化或数据库入库练习。本项目使用公开榜单页面，仅作学习与作品展示使用。

## 技术栈

- 编程语言：Python
- 网络请求：Requests
- 页面解析：BeautifulSoup4
- 数据输出：CSV / utf-8-sig
- 数据校验：记录数、排名连续性、评分范围、电影名重复校验

## 流程梳理

1. 按 25 条/页遍历 10 个 Top250 榜单页面。
2. 解析每条电影的排名、电影名、评分和榜单短评。
3. 对短评节点缺失保留为空值，保证字段结构稳定，不伪造短评内容。
4. 校验是否采集到 250 条记录，排名是否为 1-250 且无重复电影名。
5. 使用 utf-8-sig 输出 CSV，便于 Windows Excel 直接打开。

## 文件说明

| 文件名 | 说明 |
| :--- | :--- |
| `douban_top250_spider.py` | 爬虫主程序，包含请求、解析、校验、输出流程 |
| `douban_top250.csv` | 项目数据文件，包含电影榜单结构化数据 |
| `requirements.txt` | Python 依赖 |

## 运行方式

安装依赖：

```bash
pip install -r requirements.txt
```

运行脚本：

```bash
python douban_top250_spider.py --output douban_top250.csv
```

如果豆瓣临时拦截或页面结构变化，脚本会提示记录数不足。调试阶段可使用：

```bash
python douban_top250_spider.py --allow-partial
```

## 项目成果

- 完成从公开网页到结构化 CSV 的采集流程。
- 对缺失短评、请求失败、记录数不足等情况做了可识别处理。
- 输出字段可直接用于评分区间分布、评分排序、高分电影筛选等分析。
